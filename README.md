### ランダム系

```
!random
```

> ランダムな駅を返す

```
!random 市町村名 | 都道府県名
```

> その自治体に属するランダムな駅を返す  
> スペース区切りで複数の自治体を指定可能(or)

### クイズ系

```
!quiz
```

> 駅idから駅名を当てるクイズ  
> リプライで回答

```
!quiz 市町村名 | 都道府県名
```

> 駅idから駅名を当てるクイズ  
> 指定の自治体内からのみ出題(スペース区切りで複数指定)  
> リプライで回答

```
!ans
```

> 出題にリプライして、その解答を表示
