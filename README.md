### ランダム系

```
!random
```

> ランダムな駅を返す

```
!random 市町村名 | 都道府県名
```

> その自治体に属するランダムな駅を返す  
> スペース区切りで複数の自治体を指定可能(or)

### クイズ系

```
!quiz
```

> 駅idから駅名を当てるクイズ  
> リプライで回答

```
!quiz 市町村名 | 都道府県名
```

> 駅idから駅名を当てるクイズ  
> 指定の自治体内からのみ出題(スペース区切りで複数指定)  
> リプライで回答

```
!ans
```

> 出題にリプライして、その解答を表示

```
!hint
```

> 出題にリプライして、そのヒントを表示

### 今日の1駅

毎朝7時（日本時間）に、日付から選ばれた駅を設定したチャンネルへ送信します。

```
/daily-station set channel:#チャンネル名
```

> 送信先チャンネルの設定  
> 午前7時以降に設定した場合、当日の駅が即座に送信されます

```
/daily-station disable
```

> 送信を止める
